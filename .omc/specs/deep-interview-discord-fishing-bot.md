## Goal
Построить полноценную игру «Рыбалка» в виде Discord-бота для **одного сервера**. Игроки через slash-команды и кнопки забрасывают удочку (с мини-игрой «Подсечь!» на тайминг), тратят восстанавливающуюся энергию, продают улов за 🪙 монеты, прокачивают снаряжение, открывают сундуки за 🐚 жемчуг, выполняют ежедневные, еженедельные и сезонные испытания, играют с ботом в блэкджек на монеты или рыбу. Играют вместе (серверный босс, общие цели) и соревнуются по категориям рейтингов. Ключевые экраны отрисовываются картинками (PNG через canvas). Объём: **вся игра сразу** (не MVP).

## Constraints
- **Масштаб:** один Discord-сервер, до ~500 игроков. Весь прогресс хранится на этом сервере. `guild_id` в схеме необязателен, но конфиг сервера (каналы, часовой пояс) задаётся.
- **Стек:** TypeScript (strict), Node.js 20+, discord.js v14, yarn. SQLite (better-sqlite3) + типобезопасный слой запросов (Drizzle ORM или Kysely), @napi-rs/canvas для картинок, планировщик (node-cron) для сбросов и событий, vitest для тестов.
- **Интерфейс:** только slash-команды, кнопки, select-меню и модалки. Никаких префикс-команд.
- **Визуализация:** обычные ответы — эмбеды с эмодзи и цветами редкости. PNG-карточки для: профиля, редкого улова (Редкая+), результата сундука, таблицы лидеров, HP босса. Веб-дашборда нет.
- **Ритм:** короткие сессии 3–5 раз в день. Полной энергии хватает на ~10–15 забросов, полное восстановление ~4 часа.
- **Валюты:** две. 🪙 Монеты (продажа рыбы → магазин снаряжения и расходников) и 🐚 Жемчуг (испытания, боссы, серии входов, первые поимки → сундуки).
- **Сезоны:** ~4 недели, тематические. Сбрасываются сезонный рейтинг и пасс. Снаряжение, монеты, жемчуг и коллекция сохраняются.
- **Социальная модель:** кооператив (босс, цели сервера) + соревнование по категориям рейтингов, чтобы у новичка тоже был шанс.
- **Баланс вынесен в данные:** рыбы, снаряжение, сундуки, испытания и числовые константы описаны в типизированных data-файлах/конфиге, а не зашиты в логику.
- **Надёжность:** все операции с валютой и инвентарём выполняются в транзакциях БД. Кнопки заброса может нажимать только их владелец. Энергия считается лениво (от `energy_updated_at`), а не тиками.
- **Секреты:** `.env` (`DISCORD_TOKEN`, `CLIENT_ID`, `GUILD_ID`), `.env.example` в репозитории.

## Non-Goals
- Мультисерверность и глобальный прогресс.
- Торговля между игроками, аукцион, дуэли на ставки, кланы/артели (кандидаты для v2; схему под них заранее не усложнять).
- Веб-дашборд и сайт-энциклопедия.
- Анимированные GIF. «Анимация» сундука делается редактированием сообщения, а итог — PNG.
- Реальные деньги и любая монетизация.
- Полный вайп прогресса в конце сезона.

## Каталог игровых систем (дизайн, значения по умолчанию)

Все числа — стартовый баланс, который можно настраивать в конфиге.

### 1. Энергия
| Параметр | Значение |
|---|---|
| Базовый максимум | 100 ⚡ |
| Стоимость заброса | 8 ⚡ (≈12 забросов) |
| Регенерация | 1 ⚡ / 2.4 мин → 0→100 за 4 ч |
| Сорвалась рыба / промах | возврат 50% стоимости |
| Энергетики (расходник) | +30 ⚡, не больше 3 использований в сутки, можно превысить максимум до 150% |

### 2. Заброс (`/fish [локация]`)
1. Проверка энергии → списание → эмбед «🎣 Заброс…».
2. Через случайные 1.5–5 с сообщение редактируется в «❗ Клюёт!» с кнопкой **Подсечь**.
3. Окно реакции 2.0 с (+ бонус удочки). Нажатие в первые 40% окна — **Идеальная подсечка**: +1 ★ качества и +10% веса. Опоздал — «Сорвалась» (возврат 50% энергии).
4. Рыба ранга Редкая и выше включает **вываживание**: 2–3 раунда, в каждом нужно нажать одну из 3 кнопок-направлений (⬅️⬆️➡️) за 3 с. Ошибка снижает качество, 2 ошибки — рыба уходит. Прочность лески даёт право на одну ошибку.
5. Результат: вид, вес, качество ★1–5, цена, XP. Для Редкой и выше — PNG-карточка улова и анонс в канал сервера (для Эпической и выше).
- Кроме рыбы попадается мусор (ботинок, водоросли, 5–10%) и мини-клад (редко, немного монет или жемчуга).
- Во время активного заброса новый начать нельзя (блокировка на пользователя).

### 3. Рыба и локации
- **Редкость (6):** Обычная (серый), Необычная (зелёный), Редкая (синий), Эпическая (фиолетовый), Легендарная (оранжевый), Мифическая (красный/радужный).
- **Качество:** ★1–5, множитель цены ×1.0 / 1.2 / 1.5 / 2.0 / 3.0.
- **Вес:** случайный в диапазоне вида. Цена = `base × (вес / средний вес) × качество`.
- **Локации (5):** Пруд (ур. 1), Река (ур. 5), Озеро (ур. 10), Море (ур. 20), Глубоководье (ур. 35). У каждой свой пул видов.
- **Время суток** (утро/день/вечер/ночь по часовому поясу сервера) влияет на пул видов.
- **Контент на старте:** ≥ 50 видов рыб (≈10 на локацию), 3–5 сезонных видов на каждый сезон.
- **Уровень игрока:** XP за улов (зависит от редкости). Уровень открывает локации и снаряжение.

### 4. Снаряжение (`/equip`, `/gear`)
| Слот | Эффект |
|---|---|
| 🎣 Удочка | + шанс редкой рыбы, + окно подсечки |
| ⚙️ Катушка | + вес, + время на вываживание |
| 🧵 Леска | допустимые ошибки при вываживании, максимальный вес без обрыва |
| 🧥 Экипировка (жилет/шляпа) | + максимум энергии, − стоимость заброса |
| 🪱 Наживка (расходник) | временный бонус к редкости или конкретным видам, N забросов |

- Тиры предметов совпадают с редкостями. Заточка +1…+5 за монеты (`/upgrade`), цена растёт экспоненциально.
- Источники: магазин (базовые тиры), сундуки (все тиры, включая эксклюзивы), награды пасса и босса.

### 5. Экономика
**🪙 Монеты (мягкая валюта):**
- Продажа рыбы: `/sell` (всё, по редкости или конкретную рыбу).
- Небольшие суммы за испытания, мусор и клады.
- Траты: снаряжение, заточка, наживка, энергетики, расширение садка.

**🐚 Жемчуг (валюта сундуков). Рыбалкой не фармится бесконечно:**
| Источник | Жемчуг |
|---|---|
| Ежедневное испытание | 2–3 за штуку |
| Все 3 ежедневных выполнены | +5 бонус |
| Еженедельное испытание | 10–15 за штуку |
| Ежедневный вход (`/daily`), серия дней | 3 + 1 за день серии (максимум 10) |
| Первая поимка нового вида | 1 / 2 / 4 / 8 / 15 / 30 по редкости |
| Участие в боссе / топ урона | 10–50 |
| Уровни сезонного пасса | указаны в таблице пасса |
| Редкий дроп при забросе | ~1% (1–3 шт.) |

**Садок:** вместимость 50 рыб, расширяется за монеты. Переполненный садок блокирует `/fish`, пока рыба не будет продана.

### 6. Сундуки (`/chest open <тип>`, `/chest info`)
| Сундук | Цена | Дроп |
|---|---|---|
| 🪵 Деревянный | 10 🐚 | монеты, наживка, энергетики, снаряжение Обычное–Редкое |
| 🥈 Серебряный | 30 🐚 | + снаряжение до Эпического, косметика (рамки профиля) |
| 🥇 Золотой | 80 🐚 | + Легендарное/Мифическое снаряжение, титулы, фоны профиля |

- **Прокрутка:** сообщение 3–4 раза редактируется, показывая ленту-рулетку из эмодзи, затем выходит PNG-карточка результата в цвете редкости.
- **Гарант (pity):** в Золотом сундуке Легендарное+ гарантировано не позже чем через 20 открытий. Счётчик хранится у игрока.
- **Прозрачность:** `/chest info` показывает шансы выпадения.
- Дубль снаряжения конвертируется в монеты или «осколки» для заточки.

### 7. Испытания (`/challenges`)
- **Ежедневные:** 3 случайных из пула. Сброс в 00:00 по часовому поясу сервера (по умолчанию Europe/Moscow). Примеры: поймать 10 рыб; 3 идеальные подсечки; поймать Редкую+; продать на 500 🪙; порыбачить в конкретной локации; поймать рыбу тяжелее X кг.
- **Еженедельные:** 4 испытания, сброс в понедельник 00:00. Примеры: 100 рыб; 3 Эпические; открыть 5 сундуков; нанести N урона боссу; найти 2 новых вида.
- **Сезонные:** 10–15 испытаний на весь сезон, сложнее (поймать все сезонные виды, выйти в топ-10 категории и т.п.), дают много сезонных XP.
- **Достижения:** постоянные, многоуровневые («Поймано 100/1000/10000 рыб», «Коллекционер 25/50/100%»). Дают титулы и жемчуг.

### 8. Сезон и пасс (`/season`, `/pass`)
- Длится 4 недели, у каждого своя тема (название, 3–5 сезонных рыб, цветовая схема карточек).
- **Пасс:** 30 уровней, сезонные XP за забросы, испытания и участие в боссе. Награды: монеты, жемчуг, сундуки, эксклюзивная косметика сезона. Бесплатный для всех (одна линия).
- **Конец сезона:** финальный рейтинг, топ-3 категорий получают постоянный титул и значок сезона. Сезонный рейтинг и пасс обнуляются, остальное остаётся. Итоги сезона анонсируются картинкой в канал.

### 9. Кооператив: серверный босс и цели
- **Босс («Легенда озера»):** появляется по расписанию (по умолчанию 2 раза в неделю) или командой админа. Живёт 24 ч, привязан к локации, общий пул HP масштабируется от числа активных игроков за неделю.
- Каждый заброс в локации босса наносит урон = f(вес, качество, идеальная подсечка). Команда `/boss` показывает PNG с полосой HP и топом урона.
- **Награды:** при победе все участники получают награду по тирам вклада, топ-1 — титул. При провале — утешительная награда.
- **Еженедельная цель сервера:** «Вместе поймать 5000 кг рыбы». Прогресс-бар в `/server`. При выполнении все активные игроки получают жемчуг.

### 10. Соревнование: рейтинги и события (`/top <категория>`)
- **Категории:** самая тяжёлая рыба недели, заработано монет за неделю, Редкие+ за неделю, % коллекции, уровень пасса, урон по боссу (за сезон), уровень игрока (за всё время).
- Недельные категории сбрасываются в понедельник, победители получают жемчуг и объявляются в канале.
- **События** (запускает админ или расписание): «Час клёва» (×2 шанс редких, 1 ч), «Турнир» (самая тяжёлая рыба за 1 ч, призы топ-3).

### 11. Статистика
- **Личная (`/profile [@user]`, `/stats [@user]`):** уровень/XP, энергия, экипировка, валюты, всего забросов/поимок/срывов, % идеальных подсечек, суммарный вес, рекорд по каждому виду, счётчики по редкостям, монеты заработано/потрачено, сундуков открыто, % коллекции, серия входов, титулы.
- **Серверная (`/server`):** всего рыб и кг, рекорды по видам с владельцами, побеждённые боссы, прогресс цели недели, активные игроки, самый редкий улов в истории.
- **Коллекция (`/collection`):** энциклопедия с пойманными и неизвестными (❓) видами, пагинация по локациям.

### 12. Блэкджек с ботом (`/blackjack`)
- **Ставка:** монеты (`/blackjack coins <сумма>`) или рыба из садка (`/blackjack fish`: select-меню до 25 рыб, можно выбрать несколько). Рыба оценивается по текущей цене продажи и изымается из садка в момент ставки. Выигрыш выплачивается монетами. При ничьей рыба возвращается в садок.
- **Жемчуг ставить нельзя** (защита экономики сундуков).
- **Лимиты:** минимальная ставка 10 🪙, максимальная `100 + 50 × уровень` 🪙 (для рыбы — по суммарной оценке). До 20 раздач в сутки на игрока, сброс вместе с ежедневными испытаниями.
- **Правила:** колода из 6 колод, перемешивается для каждой раздачи. Дилер добирает до 17 и стоит на soft 17. Блэкджек платит 3:2, обычная победа 1:1, ничья возвращает ставку. Действия: **Взять**, **Хватит**, **Удвоить** (только на первых двух картах, монетная ставка, если хватает монет). Сплита и страховки нет.
- **Интерфейс:** эмбед со столом (`A♠ K♥`, суммы, скрытая карта дилера 🂠) и кнопками. Нажимать может только владелец раздачи. Через 60 с бездействия засчитывается автоматическое «Хватит». Итог раздачи рисуется PNG-карточкой стола.
- **Надёжность:** ставка списывается в транзакции при старте, выплата — в транзакции при завершении. Незавершённые раздачи хранятся в БД и доигрываются автоматическим «Хватит» при рестарте бота. Одновременно у игрока может быть только одна раздача.
- **Статистика и рейтинг:** раздач, побед/поражений/ничьих, блэкджеков, чистый результат, самый крупный выигрыш. Категория `/top` «🃏 Казино: чистый выигрыш за неделю».
- **Связь с испытаниями:** в пул ежедневных добавляется испытание «Сыграть 3 раздачи» с наградой в монетах, не в жемчуге.

## Acceptance Criteria
- [ ] `yarn build` проходит без ошибок TS (strict). `yarn test` зелёный. `yarn dev` запускает бота с токеном из `.env`, slash-команды регистрируются на `GUILD_ID`.
- [ ] `/fish` списывает 8 ⚡. Если энергии не хватает, приходит отказ с временем до восстановления. Регенерация 1 ⚡ / 2.4 мин проверяется юнит-тестом с подменой времени.
- [ ] Кнопка «Подсечь» появляется через 1.5–5 с. Нажатие вовремя даёт улов, в первые 40% окна — идеальная подсечка (+1★). Опоздание — «Сорвалась» и возврат 4 ⚡. Чужой пользователь нажать кнопку не может.
- [ ] Для Редкой+ рыбы запускается вываживание из 2–3 раундов. Две ошибки — рыба уходит (при леске без бонуса).

- [ ] Снаряжение меняет характеристики: максимум энергии, стоимость заброса, шанс редкости, окно подсечки. Каждый эффект покрыт тестом.

## Technical Context
Greenfield: папка пустая, в project memory указано JS/TS + yarn.

Рекомендуемая структура:
```
src/
  index.ts                 # клиент, загрузка команд/обработчиков
  config.ts                # env + игровые константы
  commands/                # по файлу на slash-команду
  interactions/            # обработчики кнопок/селектов (customId-роутинг)
  game/                    # чистая доменная логика без discord.js: energy, cast, loot, economy, challenges, boss, season
  data/                    # fish.ts, gear.ts, chests.ts, challenges.ts, locations.ts, seasons.ts
  db/                      # схема, миграции, репозитории
  render/                  # canvas-карточки: profile, catch, chest, leaderboard, boss
  scheduler/               # cron: daily/weekly reset, boss spawn, season end
  lib/rng.ts               # seedable RNG для тестов
tests/
```
- Доменная логика (`game/`) — чистые функции с внедряемыми `now()` и `rng()`, чтобы тестировать без Discord.
- Игровые события (улов, продажа, сундук) идут через внутреннюю шину событий, на которую подписаны трекеры испытаний, пасса, босса и целей сервера.
- Шрифты для canvas кладутся в репозиторий (например, Inter/Roboto с кириллицей), иконки — эмодзи Twemoji.
